# 最后一个边界案例的根因（2026-11-24）

## 数学问题

该例是人工构造的 78 个均匀圆周相位：`phi_j = 2*pi*j/78`。

`A_ij = cos(phi_i - phi_j) = c_i*c_j + s_i*s_j`。

由于 `c'*c = s'*s = 39`、`c'*s = 0`，精确数学中的两个非零特征值均为 **39**。浮点参考值为 `39.00000000000001` 和 `38.99999999999999`，间隔仅 `1.42e-14`。

重根对应的正交特征向量可以在同一个二维子空间内旋转。原 WEiDA 特征却是 `sum(lambda_i*v_i)/sum(lambda_i)`；在这里主要为 `(v1+v2)/2`，会随所选基变化。最后整体翻转符号不能消除一般旋转。这一不稳定性来自原公式对特征向量基的依赖。

## Python 逐步定位

使用相同 MATLAB 起点、固定 C 内存布局，在 Windows / NumPy 2.4.6 重算：

- 第一次迭代后的基向量差约 `1.39e-16`。
- 第二次迭代残差约 `1.12e-14`；归一化后，下一个基向量差放大到约 `0.419`。
- 最终特征对残差约 `5.33e-15`，主二维子空间投影矩阵差约 `3.12e-17`。
- 原始特征差约 `0.209`；即便只为诊断允许整体翻转，差仍约 `0.0867`。因此包含选基旋转，不能仅用符号修正解释。

两边都能算出正确的主子空间，仍可能得到不同的 WEiDA 特征。固定起点不足以消除舍入路径的影响。上述具体数值随平台和矩阵布局变化，不能与另一运行的最大误差混为同一次测量。

## MATLAB 内部的对照实验

`diagnose_degenerate.m` 在同一个 MATLAB 运行中，分别对普通随机相位和圆周边界矩阵测试：重复调用、起点一 ULP 改动、起点约 `1e-15` 改动、矩阵一 ULP 改动及矩阵 `1e-12` 改动。记录原始特征、允许整体翻转后的诊断差、主子空间投影差、特征值变化、残差和收敛状态。

[R2025b Update 7 实测运行](https://github.com/LevelDownRefine/WEIDA/actions/runs/45213319402)，完整结果保存在 [JSON](degenerate_sensitivity_r2025b.json)：

| 同一 MATLAB 内的改动 | 改动量 | 圆周例特征变化 | 普通对照特征变化 |
|---|---:|---:|---:|
| 原样重复 | 0 | 0 | 0 |
| 起点单元素一 ULP | 1.39e-17 | **0.031535** | 1.11e-16 |
| 矩阵对角元素一 ULP | 2.22e-16 | **0.009125** | 1.11e-16 |
| 矩阵对称非对角元素一 ULP | 1.11e-16 | **0.225606** | 1.53e-16 |
| 矩阵对角元素约 1e-12 | 1.00e-12 | **0.136213** | 1.16e-14 |

全部求解收敛。起点一 ULP 改动时，矩阵完全相同，主子空间投影差仅 `5.20e-17`；特征允许整体翻转后的差仍为 `0.031535`。非对角一 ULP 改动的特征即使允许整体翻转，差仍为 `0.019288`。

因此，此处已实证原 MATLAB 实现自身对重根选基的舍入细节敏感；这不是用小的特征方程残差就能排除的问题。原样重复依然完全一致，不能误称 MATLAB 在相同输入与设置下随机不确定。
